## Idea
Parents with limited education struggle to support kids who study in English-medium schools — especially during homework and exam prep.

## Vision
A “Co-Teacher in Your Pocket” that turns any parent, regardless of education, into a confident guide for their child’s learning.

## What the Hackathon Demo Should Feel Like
Think:
A parent takes a photo → app understands the homework → explains it in simple Hindi → guides the parent through teaching → checks child’s understanding → generates revision mocks.

The magic moment is:
Parent + Kid + AI working together.


I’ll break it into 3 layers:
	1.	Absolute Bare-Minimum (Must Ship)
	2.	High-Impact Add-Ons (Should Ship if time allows)
	3.	Wow Layer (If things go extremely well)

Each layer builds on the previous one.

⸻

⭐ TIER 1 — ABSOLUTE BARE MINI­MUM (MUST SHIP)

This is the smallest set of features that STILL gives you a hackathon-winning demo.

If you deliver only this tier, you will still blow minds.

✔️ 1. Multi-Kid Dashboard

Two kids → Class 4 English + Class 8 Chemistry.
Effort: Very low
Value: Sets context for everything else.

⸻

✔️ 2. BIG “Scan Homework” Button

Parents → scan → magic happens.
One action → deep value.

Effort: Low
Value: Massive UX clarity + Demo magic.

⸻

✔️ 3. Vision → Understanding → Topic Detection

Core magic moment:
Parent uploads NCERT page → AI identifies:
	•	Subject
	•	Chapter
	•	Question type

Effort: Medium
Value: The wow moment of the app.

⸻

✔️ 4. Guided Parent Session (Minimal Version)

Only these components:
	•	🧠 Parent Context (simple text)
	•	🗣 Speak-to-child script (one or two lines)
	•	Final answer generation

NO visuals yet
NO audio yet
NO weakness tracking
NO revision mode

Effort: Medium
Value: Emotional empowerment → parents feel “I can teach!”

⸻

✔️ 5. Switching Kids → Running same flow on next kid

Just run the flow on Chemistry too.

Effort: Low (just reuse logic)
Value: Massive perceptual value → “Multikid! Multi-subject! Adaptive!”

⸻

✔️ WHAT THE DEMO LOOKS LIKE AT THIS TIER
	•	Parent chooses Riya → scans English homework → gets guided session → answer
	•	Parent switches to Aarav → scans Chemistry homework → guided session → answer

And you STOP.

This alone is hackathon-finalist-level.

⸻

⭐ TIER 2 — HIGH-IMPACT ADD-ONS (SHOULD ADD IF TIME ALLOWS)

These features add depth but are not essential for a functional demo.
They multiply the perceived intelligence of the system.

⸻

⭐ 6. Audio-First Playback (Tap-to-Play Hindi Voice)

This is a major value-add with very little engineering complexity.

Use built-in TTS → no need for fancy audio LLMs.

Why add this?
Parents with low literacy → instant inclusion.

Effort: Medium
Value: Sky-high (demo judges LOVE inclusive design)

⸻

⭐ 7. “Understand vs Speak Script” Split

Two sections:
	•	Parent Context
	•	Speak to Child

Only add this once your core guided session is stable.

Effort: Low
Value: Huge usability clarity → shows deep understanding of user persona.

⸻

⭐ 8. Auto Visual Cue (simple generated image)

Even a single static image (sun rays, molecule diagram) is huge.

Effort: Medium
Value: Very high (kid engagement + demo delight)

⸻

⭐ 9. Minimal Weakness Tracking (Basic Counters)

No ML.
Just count tags like:
	•	Vocabulary issues
	•	Concept confusion
	•	Wrong MCQs
	•	Fast/slow answers

And show simple text like:

“Based on today’s session, Aarav struggled with:
• Concept differentiation
• Diagram labeling”

Even static rules will look magical.

Effort: Medium
Value: Very high (makes system feel “smart”)

⸻

⭐ TIER 3 — WOW LAYER (IF TIME + ENERGY ALLOW)

These features will make your product a FULL, truly complete prototype.
But they are NOT required for winning the hackathon.

⸻

🌟 10. Revision / Mock Exam Mode

For each kid:
	•	MCQs
	•	Short answers
	•	Vocab cards
	•	Oral questions

This is a self-contained module and can be reused across subjects.

Effort: Medium-High
Value: Extremely high (parents LOVE revision tools).

⸻

🌟 11. Micro-Sessions for Fixing Weaknesses

The “Fix this in 5 minutes” button.

This can simply:
	•	Regenerate a guided session
	•	Focus on a weakness tag

Effort: Medium
Value: Makes product feel alive + personalized.

⸻

🌟 12. Clean Analytics Page (“Learning Radar”)

A tiny dashboard summarizing:
	•	Today’s sessions
	•	Mistakes
	•	Improvements
	•	Suggested next actions

Effort: Medium
Value: Gives polish + completeness.
